환경 설정

필수 패키지 설치

# 가상환경 생성 (최초 1회)
python -m venv .venv

# 활성화 (Windows PowerShell)
.venv\Scripts\Activate.ps1

# 의존성 설치
pip install -r backend/requirements.txt

테스트 전용 추가 패키지

pip install pytest pytest-asyncio httpx uvicorn

pytest.ini 설정

[pytest]
asyncio_mode = auto    # 모든 async def test_* 자동으로 코루틴 실행
testpaths = tests      # 테스트 탐색 루트

asyncio_mode = auto — @pytest.mark.asyncio 데코레이터 없이도 async def 테스트가 자동 실행된다. pytest-asyncio 0.21+ 필요.

단위 테스트는 conftest.py의 fixture가 monkeypatch로 환경변수를 주입한다. 별도 .env 파일 불필요.

Fixture 구조

공통 Fixture (conftest.py)

# tests/conftest.py

@pytest_asyncio.fixture
async def client(tmp_path, monkeypatch):
    """비인증 ASGI 클라이언트. 모든 테스트의 베이스."""
    monkeypatch.setenv("DATA_DIR", str(tmp_path / "data"))
    monkeypatch.setenv("PHOTO_ROOT", str(tmp_path / "photos"))
    monkeypatch.setenv("ADMIN_PASSWORD", "testpass")
    monkeypatch.setenv("JWT_SECRET", "testsecret")
    (tmp_path / "photos").mkdir(parents=True, exist_ok=True)

    from backend.models.database import init_db
    await init_db()

    from backend.main import app
    async with AsyncClient(transport=ASGITransport(app=app),
                            base_url="http://test") as c:
        yield c


@pytest_asyncio.fixture
async def admin_client(client):
    """Admin JWT가 헤더에 설정된 클라이언트."""
    r = await client.post("/api/auth/login", json={"password": "testpass"})
    client.headers["Authorization"] = f"Bearer {r.json()['access_token']}"
    yield client

function scope (기본) — 각 테스트마다 새 SQLite DB(in-memory, tmp_path 기반)가 생성된다. 테스트 간 상태 오염 없음.

자주 발생하는 오류

증상원인해결
모듈 임포트 오류 시스템 Python 사용 중 .venv\Scripts\python -m pytest 사용
asyncio 관련 경고 pytest-asyncio 버전 불일치 pytest.ini에 asyncio_mode = auto 확인
E2E 서버 시작 실패 포트 충돌 또는 uvicorn 미설치 pip install uvicorn, 포트 자동 배정 로직 확인
썸네일 테스트 경로 오류 Windows 백슬래시 경로 Path(...).as_posix() 사용 (이미 적용됨)
DB 이미 초기화됨 오류 테스트 간 DB 공유 각 테스트는 function-scope fixture 사용 — 문제 없음
