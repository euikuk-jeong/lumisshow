# mySlideshows - 요구사항 및 프로젝트 계획

## 1. 프로젝트 개요

Synology NAS 위에서 Docker 컨테이너로 동작하는 사진 앨범 및 슬라이드쇼 웹 애플리케이션.
Container Manager를 통해 배포되며, NAS에 저장된 사진을 기반으로 앨범을 구성하고 공유 링크를 통해 슬라이드쇼를 제공한다.

---

## 2. 기능 요구사항

### FR-01. 앨범 관리 (Admin 전용)

| ID | 요구사항 |
|----|----------|
| FR-01-1 | 관리자는 NAS 사진 폴더를 탐색하여 이름, 날짜, 폴더 경로, 파일명 조건으로 사진을 검색·선택할 수 있다. |
| FR-01-2 | 선택한 사진으로 특정 이름의 앨범을 생성할 수 있다. |
| FR-01-3 | 생성된 앨범에 사진을 추가하거나, 앨범 목록에서 제외할 수 있다(파일 삭제 아님). |
| FR-01-4 | 앨범 이름을 변경하거나 앨범을 삭제할 수 있다. |
| FR-01-5 | 앨범에 공유 링크를 생성할 수 있다. |
| FR-01-6 | 공유 링크에 패스워드 보호 또는 만료일(expiry date)을 설정할 수 있다. |

### FR-02. 공유 링크 접속 화면 (비인증 사용자)

| ID | 요구사항 |
|----|----------|
| FR-02-1 | 링크로 접속 시 패스워드가 설정된 경우 패스워드 입력 화면을 먼저 표시한다. |
| FR-02-2 | 만료된 링크는 접근을 차단하고 만료 안내 메시지를 표시한다. |
| FR-02-3 | 앨범 메인 화면에는 앨범 이름, 이미지 수, 생성일, 만료일을 표시한다. |
| FR-02-4 | 앨범 메인 화면에 슬라이드쇼 시작 버튼을 제공한다. |
| FR-02-5 | 앨범 메인 화면에 슬라이드쇼 설정 버튼을 제공한다(전환 시간, 배경음악 ON/OFF 등). |
| FR-02-6 | 앨범 메인 화면에 앨범 전체 이미지를 ZIP으로 다운로드하는 버튼을 제공한다. |

### FR-03. 슬라이드쇼

| ID | 요구사항 |
|----|----------|
| FR-03-1 | 사진은 설정된 시간 간격으로 자동 전환된다. |
| FR-03-2 | 사진 전환 시 랜덤 전환 효과(fade, slide, zoom, flip, blur 등)가 적용된다. |
| FR-03-3 | 사진을 표시하는 동안 이미지가 랜덤한 방향으로 천천히 이동하는 Ken Burns 효과가 적용된다. |
| FR-03-4 | 좌우 화살표 버튼(화면 끝) 및 키보드 방향키로 이전/다음 사진으로 이동할 수 있다. |
| FR-03-5 | 수동 이동 시에도 자동 전환과 동일한 전환 효과가 적용된다. |
| FR-03-6 | 현재 표시 중인 사진에 대한 개별 다운로드 버튼을 제공한다. |
| FR-03-7 | 슬라이드쇼 중 일시정지/재개가 가능하다. |
| FR-03-8 | 슬라이드쇼에서 앨범 메인 화면으로 돌아갈 수 있다. |

### FR-04. 배경음악 (옵션)

| ID | 요구사항 |
|----|----------|
| FR-04-1 | 관리자는 앨범에 배경음악 파일(MP3 등)을 업로드하거나 NAS 내 오디오 파일을 지정할 수 있다. |
| FR-04-2 | 사용자는 슬라이드쇼 설정에서 배경음악 ON/OFF를 선택할 수 있다. |
| FR-04-3 | 배경음악은 슬라이드쇼 시작 시 재생되며 반복(loop) 재생된다. |
| FR-04-4 | 음량 조절 UI를 제공한다. |

## 3. 비기능 요구사항

| ID | 요구사항 |
|----|----------|
| NFR-01 | Docker 단일 컨테이너 또는 docker-compose 구성으로 배포 가능해야 한다. |
| NFR-02 | Synology Container Manager(docker-compose v2 기반)와 호환되어야 한다. |
| NFR-03 | NAS의 사진 폴더는 볼륨 마운트로 연결되어 원본 파일을 변경하지 않는다. |
| NFR-04 | 앨범 메타데이터(구성 정보, 링크, 설정)는 컨테이너 외부 볼륨에 영속적으로 저장된다. |
| NFR-05 | 모바일 브라우저(터치 스와이프)와 데스크톱 브라우저를 모두 지원한다. |
| NFR-06 | 대용량 이미지에 대한 썸네일 캐시를 생성하여 로딩 성능을 최적화한다. |
| NFR-07 | 관리자 인증은 환경변수로 설정된 계정을 사용한다(단일 Admin 계정). |

## 4. 사용자 역할

| 역할 | 설명 |
|------|------|
| Admin | 앨범 생성/편집/삭제, 사진 추가/제외, 공유 링크 관리, 배경음악 설정 가능 |
| 공유 링크 사용자 | 공유 링크로 접속, 앨범 보기, 슬라이드쇼, 다운로드만 가능 |

## 5. 기술 스택

| 영역 | 선택 기술 | 이유 |
|------|-----------|------|
| Backend | Python / FastAPI | 가볍고 비동기 처리 적합, 이미지 처리 라이브러리 풍부 |
| Frontend | **Vanilla JS + HTML/CSS** | 빌드 도구 불필요, DOM 직접 제어로 슬라이드쇼 엔진 구현에 최적, 외부 의존성 없음 |
| 이미지 처리 | Pillow (PIL) | 썸네일 생성, EXIF 파싱 |
| 데이터 저장 | SQLite | 경량, 파일 기반, NAS 볼륨에 영속 저장 |
| 미디어 서빙 | FastAPI StaticFiles | 대용량 파일 직접 서빙 (Nginx 불필요) |
| 컨테이너 | Docker + docker-compose | Synology Container Manager 호환 |
| 다운로드 ZIP | Python zipfile / streaming | 서버 메모리 절약을 위한 스트리밍 ZIP |

## 8. 제약사항 및 고려사항

- NAS 원본 사진 폴더는 **읽기 전용** 마운트를 권장 (원본 보호)
- 썸네일 캐시는 별도 볼륨에 저장하여 컨테이너 재시작 시 손실 방지
- 대용량 앨범(1000장 이상)의 ZIP 다운로드는 스트리밍 방식으로 처리
- 공유 링크 URL은 추측 불가한 랜덤 토큰(UUID v4) 사용
- 배경음악 파일은 브라우저 자동재생 정책(user gesture 필요) 고려 필요
- 모바일 터치: swipe left/right로 슬라이드 전환 지원
