⚡ 서버 실행 방법

PowerShell 또는 터미널에서 프로젝트 루트(D:\Work\working\mySlideshows)에서 실행:

# 가상환경 활성화 (Windows PowerShell)
.\.venv\Scripts\Activate.ps1

# 환경변수 설정
$env:ADMIN_PASSWORD="dev_password"
$env:JWT_SECRET="dev_secret_key"
$env:PHOTO_ROOT="./testdata/photos"
$env:DATA_DIR="./testdata/data"
$env:BASE_URL="http://localhost:8080"

# 서버 실행
uvicorn backend.main:app --reload --host 0.0.0.0 --port 8080

✅ 서버 준비 완료 메시지: Application startup complete.
🌐 접속 주소: http://localhost:8080
🗂 API 문서: http://localhost:8080/docs

📁 테스트 데이터 확인

PHOTO_ROOT=./testdata/photos에 사진 파일이 있어야 탐색기 테스트가 가능합니다.

# testdata 폴더 구조 예시 (없으면 생성)
mkdir -p testdata/photos/2024/trip
# 샘플 jpg 파일 복사 또는 다운로드
