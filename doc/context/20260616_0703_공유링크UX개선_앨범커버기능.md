## 작업 목록

- **api.patch 누락 버그 수정** (`frontend/assets/js/api.js`)
  - `api` 객체에 `patch` 메서드가 없어 공유링크 비활성화 시 에러 발생 → 추가

- **공유링크 hash 단축** (`backend/routers/admin_links.py`)
  - `uuid4()` (36자) → `secrets.token_hex(5)` (10자, 소문자 hex)
  - 기존 링크 영향 없음, 신규 생성분부터 적용

- **만료일 timezone 버그 분석 및 수정** (`admin-album-edit.js`, 분석)
  - 원인: `datetime-local` 입력값이 로컬 시간이지만 백엔드가 UTC로 해석 → 시간 오차 발생
  - 수정: 입력을 `type="date"` (날짜만)로 변경, 전송 시 `T23:59:59` 붙여 UTC 하루 끝으로 명시
  - 백엔드 만료 체크 로직(`_get_valid_link`, SQL `datetime('now')`) 자체는 정상 확인

- **날짜 picker UI 정리** (`admin-album-edit.js`, `admin.css`)
  - 팝업 방식 시도 → 사용자 요청으로 인라인으로 변경
  - 최종: `input[type="date"]` + "지우기" 버튼만 (선택 버튼 제거)

- **앨범 커버 설정 기능** (`admin-album-edit.js`, `admin.css`)
  - 사진 썸네일 hover 시 "커버로 설정" 버튼 표시 (좌하단)
  - 현재 커버 사진에 "커버" 배지 표시 (좌상단, primary 색상)
  - `PUT /api/admin/albums/{id}` 호출 후 UI 즉시 반영 (재로드 없음)
  - 백엔드(`AlbumUpdate`, `admin_albums.py`)는 이미 `cover_path` 처리 가능했음

- **앨범 목록 커버 표시** (`admin-albums.js`)
  - 이미 `album.cover_path`를 사용한 표시 로직이 구현되어 있었음 (별도 수정 불필요)

- **커버 → 슬라이드쇼 첫 이미지 반영**
  - `backend/models/schemas.py`: `ShareAlbumResponse`에 `cover_index: Optional[int]` 추가
  - `backend/routers/share.py`: `get_album`에서 커버 사진의 sort_order 기준 위치 계산 후 반환
  - `frontend/assets/js/pages/slideshow.js`: `startIdx` 우선순위를 `?i=N` → `cover_index` → `0` 순으로 변경
  - `frontend/assets/js/pages/album-view.js`: 뷰어 페이지 커버 이미지도 `cover_index` 기준 적용 (기존 `photos[0]` 하드코딩 제거)
