## 보안 검토 결과 (어드바이저)

### 수정 필요 항목

| 심각도 | 위치 | 내용 |
|--------|------|------|
| Medium | `share.py` | `POST /api/share/{token}/auth` 속도 제한 없음 → 패스워드 브루트포스 가능 |
| Low-Medium | `media.py` | `serve_media`/`serve_thumb` PHOTO_ROOT containment check 없음 |
| Low-Medium | `admin_browse.py` | Admin JWT가 `?token=` query param으로 전달 → 서버 로그/Referer 유출 |
| Low/Design | `main.py` | insecure default 사용 시 경고만 출력, 서버는 정상 동작 |
| Low | `admin-albums.js:39`, `admin-album-edit.js:83` | `innerHTML`에 `esc()` 없이 `e.message` 삽입 |

### 안전 확인 사항
- SQL: 모두 파라미터화, 동적 컬럼은 화이트리스트 검증 ✓
- XSS: 게스트 뷰어의 album_name/description 등 `esc()` 처리 ✓
- JWT: `algorithms=["HS256"]` 고정, `none` 알고리즘 공격 불가 ✓
- 크로스-앨범 격리: `_verify_file_in_album` exact-match join + `sub==share:{token}` 이중 검증 ✓
- 쿠키 플래그: `httponly`, `samesite`, `secure`(https 시) 정상 ✓
- ZIP 다운로드: 파일명 sanitize, Content-Disposition 헤더 인젝션 없음 ✓
