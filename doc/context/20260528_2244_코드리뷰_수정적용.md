## 주요 결정 사항

- `music_path` containment: `os.path.realpath` + `startswith(DATA_DIR/music/)` 방식 채택 — 기존 테스트의 절대경로 사용 패턴과 호환됨
- `JWT_SECRET`/`ADMIN_PASSWORD` 검증: crash 대신 warning 로그 채택 — `docker-compose.yml`이 이미 `:?` syntax으로 필수 env var 강제하므로 충분
- `admin_links.py`의 `_get_album_or_404` 중복 코드: 기능 정확성 문제 없어 이번 세션에서 수정 제외 (향후 공유 유틸 모듈 분리 시 처리)
- `exif_transpose` 제거 후 회전 처리: orientation 태그 5,6,7,8에서 width/height 스왑으로 대체 → 픽셀 디코딩 없이 올바른 표시 치수 반환
